# План типового этажа — инструкция по запуску

Интерактивная веб-презентация плана типового этажа многоквартирного жилого дома.
Сборки, бандлера и серверной части **нет**: это статические HTML/CSS/JS-файлы, которые
рисуют SVG прямо в браузере из объекта данных `FLOOR_DATA`.

---

## 1. Состав папки

```
plan-tipovogo-etazha/
├── index.html            точка входа (вся вёрстка презентации)
├── css/
│   ├── ui.css            интерфейс, шапка, карточки, темы
│   ├── plan.css          стили чертежа (стены, проёмы, подписи, штамп)
│   └── charts.css        стили диаграмм, аксонометрии и объёмной схемы
├── js/
│   ├── geometry.js       математика плана: полигоны, площади, форматирование
│   ├── data.js           ДЕМО-ДАННЫЕ: объект FLOOR_DATA (ваш план подставляется сюда)
│   ├── render-plan.js    сборка SVG-листа (план, размеры, оси, штамп, примечания)
│   ├── render-iso.js     аксонометрия «кукольный домик» и объёмная схема здания
│   ├── charts.js         диаграммы: донат зон, квартиры, стек, роза окон, гейдж, этажи
│   └── app.js            оркестрация: вкладки, зум, слои, редактор данных, печать
├── DATA.md               схема FLOOR_DATA и способы подстановки своих данных
├── README.md             ← вы здесь
└── tools/qa/
    ├── check.js          headless-QA: геометрия, рендер, диаграммы, нормативы (без зависимостей)
    ├── render.js         контрольный растр видов в PNG (нужен @resvg/resvg-js)
    └── .gitignore        node_modules и png не коммитятся
```

## 2. Запуск презентации

### Способ А — просто открыть файл
Двойной клик по `index.html`. Модулей ES и `fetch` нет, поэтому работа с диска (`file://`)
поддерживается: скрипты подключены обычными тегами `<script src>` в фиксированном порядке
`geometry → data → render-plan → render-iso → charts → app`.

### Способ Б — локальный статический сервер (рекомендуется)
```bash
cd plan-tipovogo-etazha
python3 -m http.server 8000            # затем http://localhost:8000
# или: npx serve .        или: php -S localhost:8000
```
Сервер удобен тем, что избавляет от любых ограничений `file://` и позволяет держать
страницу открытой во время правок `js/data.js` (обновление — Ctrl+F5).

### Способ В — в песочнице Arena
Превью уже поднято процессом:
```bash
python3 -m http.server 8042 --bind 0.0.0.0 --directory /home/user/es5/plan-tipovogo-etazha
```
Если процесс уснул после перезапуска окружения — выполните команду снова (или поднимите
любой другой сервер на этом каталоге) и откройте живой просмотр на порту 8042.

### Требования
* Любой современный браузер (Chrome, Firefox, Safari, Edge): нужны CSS-переменные и SVG 1.1/2.
* Node.js ≥ 16 — **только** для QA-скриптов (способы А/Б работают без Node).
* Сеть не нужна: шрифты системные, внешних библиотек нет.

## 3. Первые две минуты (что посмотреть)

1. **Первый экран** — факты этажа, объёмная схема здания с подсвеченным типовым этажом.
2. Вкладка **«Чертёж»** — лист АР-07: план с цветными зонами, мебелью, осями, размерами,
   штампом и примечаниями. Панель над планом: зум `− / + / ⤢`, переключатели слоёв
   «Все / Чертежи / Ч/Б», тумблер «Штриховка стен», фокус по квартирам (клик по бирке КВ.
   или по комнате — подсветка квартиры и её показателей).
3. **«Экспликация»** — таблица помещений с площадями и зонами (кнопка CSV — выгрузка).
4. **«Квартирография»** и **«Аналитика»** — диаграммы: донат зон, структуры этажа, площади
   квартир, роза остекления по фасадам, гейдж эффективности, нормоконтроль.
5. **«Ядро»** — фрагмент лестнично-лифтового узла крупнее + инженерные маркеры.
6. **«ТЭП»** — технико-экономические показатели этажа и корпуса.
7. **«Данные»** — редактор `FLOOR_DATA`: правите JSON → «Применить и пересобрать»;
   «Скачать JSON» / «Сбросить»; там же подсказки по системе координат.
8. Кнопки шапки: `◐` — тема, **«Печать листа»** — печатная форма, **«SVG»** — скачать текущий лист.

Печать: Ctrl+P → формат **A3 альбомный**, включить «Фоновая графика» (иначе не уйдут
заливки зон и штриховка). Печатается только лист; интерфейс скрывается классом `no-print`.

## 4. Подставить свои данные

Подробная схема — в **DATA.md** (блоки объекта, помещения, проёмы, лестницы, лифты, стояки,
мебель, оси, примечания; что можно не указывать и что досчитается автоматически).

Три пути, от быстрого к финальному:
1. Вкладка **«Данные»** → вставить JSON в редактор → «Применить и пересобрать».
2. Там же «Скачать JSON» / загрузить свой файл — для обмена и версионирования.
3. Заменить объект `FLOOR_DATA` в `js/data.js` — для интеграции в репозиторий.

Минимум для работы — непустой массив `rooms` (см. пример в конце DATA.md): габарит, стены,
подписи, бирки квартир, диаграммы и аксонометрия пересчитаются сами.

## 5. QA-контур (для правок геометрии и данных)

```bash
cd plan-tipovogo-etazha
node tools/qa/check.js          # без зависимостей; exit code 1 при любой ошибке
```
Что проверяет: согласование габарита и площадей; квартирографию; пересечения помещений
(семплированием); непокрытые «дыры» между помещениями и стенами; положение проёмов на осях
стен; мебель внутри помещений; сборку плана/аксонометрии/объёмной схемы (XML-корректность,
отсутствие `NaN`, валидность всех числовых атрибутов); построение шести диаграмм;
нормативные габариты (марши ≥ 1,2 м, коридоры ≥ 1,0 м, жилые ≥ 8 м²).

Контрольный растр (посмотреть лист «глазами» без браузера):
```bash
npm i --prefix tools/qa @resvg/resvg-js     # один раз
node tools/qa/render.js                     # → tools/qa/png/01…04.png
```
Известная особенность растеризатора: resvg падает на элементах с `opacity`, лежащих строго
за пределами viewBox (квартирные фрагменты плана). Это ограничение resvg, в браузере такие
виды корректны; поэтому `render.js` печатает полный лист, а фрагменты смотрят в браузере.

## 6. Возможные проблемы и решения

| Симптом | Причина / решение |
|---|---|
| Пустая страница | Открыта консоль с ошибкой: проверьте порядок `<script>` в `index.html`; при правках файлов сбросьте кэш (Ctrl+F5) |
| Нет заливок/штриховки при печати | В диалоге печати не включена «Фоновая графика» |
| В QA-растре серые зоны вместо цветных | Подстановка CSS-переменных делается внутри `render.js`; не убирайте блок `.replace(/var\(--…` |
| `node tools/qa/render.js` говорит «Нет @resvg/resvg-js» | Выполните `npm i --prefix tools/qa @resvg/resvg-js` |
| `git push` отвечает ошибкой аутентификации | Токен GitHub в окружении недействителен — переподключите GitHub в Arena и повторите push |
