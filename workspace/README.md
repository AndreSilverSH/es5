# Пакет XLSX

В этой папке находятся все 95 книг XLSX, сформированных по HTML-документам, а также `manifest.csv` с соответствием имён исходным файлам и эта инструкция.

Имена книг описывают содержимое: для фрагментов указаны тип материала и номер раздела. Подпапки `anno/`, `erra/`, `rev1/` и `plan-tipovogo-etazha/` сохранены.

Чтобы скачать весь набор сразу, используйте архив `workspace.zip`. Внутри архива содержимое находится в папке `workspace/`.
