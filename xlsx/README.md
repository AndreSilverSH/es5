# Версии HTML-документов в формате XLSX

В этом каталоге лежат Excel-книги для HTML-файлов репозитория. Имя каждой книги сформировано по заголовку документа или раздела; у фрагментов к нему добавлен тип материала (аннотация, исправление или редакция 5.1) и номер раздела. Структура подпапок `anno/`, `erra/` и `rev1/` сохранена. Файл [`manifest.csv`](manifest.csv) связывает новое имя книги с исходным HTML.

Каждый файл содержит лист **«Содержимое»**. Материал идёт в порядке исходной страницы: заголовки, абзацы, элементы списков, определения и строки HTML-таблиц. В таблицах значения ячеек сохранены в отдельных столбцах; навигация сайта и скрипты не включены. Это структурированная текстовая выгрузка, а не точная копия веб-вёрстки: стили и изображения не переносятся. Текст сохраняется как текст, а не как формулы Excel.

Чтобы обновить выгрузки после правок HTML-файлов:

```sh
python -m pip install -r tools/requirements-html-to-xlsx.txt
python tools/html_to_xlsx.py
```
